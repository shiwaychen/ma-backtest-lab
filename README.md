# MA Backtest Lab · 双均线策略回测实验室

一个可交互的双均线（金叉 / 死叉）趋势策略回测应用。参数可调、结果实时重算，
用来回答一个朴素的问题：**均线参数怎么选，凭什么是它？**

> 在线演示（Live Demo）：部署后填入 Streamlit 链接

## 功能

- 侧边栏调参：交易对（BTC / ETH / SOL）、回测天数（365 / 730 / 1095）、快线与慢线周期
- 指标卡片：策略总收益、最大回撤、完整交易次数、胜率
- 收益曲线：策略净值 vs 买入持有（Buy & Hold）基准
- 近期交易明细表与固定的「结论」区

## 回测口径（诚实性约定）

- **信号与成交分离**：收盘价产生信号，**次日开盘价成交**，避免使用未来信息（未来函数）
- **手续费**：每边 0.1%，买卖各扣一次
- **仓位**：全仓做多现货，不加杠杆，不做空
- **数据**：币安公共行情接口（日线 K 线），无需 API Key

## 核心结论（BTC 日线，近 3 年）

| 参数（快/慢） | 策略收益 | 买入持有 | 最大回撤 | 交易次数 | 胜率 |
|---|---|---|---|---|---|
| 20 / 60 | +45.1% | +121.6% | −36.8% | 11 | 36% |
| 10 / 30 | +34.2% | +118.9% | −37.8% | 22 | 32% |

- **10/30 被数据淘汰**：均线越短越敏感，横盘期假交叉（whipsaw）激增，交易次数翻倍，
  多出的大多是小亏单，手续费再磨掉约 4 个百分点——三项指标全面更差。
- **胜率只有 36% 却仍然盈利**：赢的平均 +22.4%（最大一笔 +41.7%），输的平均 −8.1%；
  靠的是盈亏比而非胜率——死叉即离场把亏损截断，让少数趋势单跑出大盈利。
- **跑输买入持有不是没用**：它的价值在回撤——最大回撤 −36.8% 对 −53.0%，
  评价策略要收益与回撤一起看。
- 命门：趋势跟踪策略在**横盘震荡市**必然连续小亏，它只在单边趋势里赚钱。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py        # 网页版
python ma_backtest.py       # 命令行版（参数在文件顶部配置区修改）
```

## 文件说明

- `app.py` — Streamlit 交互式回测网页
- `ma_backtest.py` — 命令行回测脚本，与网页版同一口径
- `requirements.txt` — 依赖清单
